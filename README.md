# DIARec: Dynamic Intention-Aware Recommendation with Attention-Based Context-Aware Item Attributes Modeling

Welcome to the official repository for **DIARec**, a context-aware sequential recommendation model designed to capture users' evolving preferences through attention-based modeling of item attributes and interaction sequences.

This repository provides the implementation and supporting materials for the research paper:

**"DIARec: Dynamic Intention-Aware Recommendation with Attention-Based Context-Aware Item Attributes Modeling"**

## Features

- **Dynamic preference modeling:** Captures users' evolving interests from sequential interactions.
- **Attention-based learning:** Models the relevance of items and contextual information in user preference representations.
- **Context-aware item attributes:** Incorporates item attributes to enrich user and item representations.
- **Sequential recommendation:** Uses users' interaction histories to generate recommendations.

## Overview

DIARec integrates sequential preference modeling and context-aware item attribute representations to improve recommendation quality. Its attention mechanisms help model the relevance of contextual information and user interactions when learning user preferences.

For the complete methodological details and experimental analysis, please refer to the original research paper.
